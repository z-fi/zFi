Probing needs a normal origin. Wallet calls work anywhere, but plain outbound requests are blocked when this page is sandboxed — serve it with cd dapp && python3 -m http.server 8080 and open it from localhost. Load the list, then Test all on Base. Each row is probed with the same request shape zSwap uses, against its own endpoint — and this page runs from the origin your keyed gateways accept, so it can test what an outside caller cannot. A row that answers gets its flag filled in and its Apply button enabled; a row that does not stays exactly as it is. Nothing claims a chain it has not answered on.
