zSwap endpoints — curated services

zEndpoints at …, on mainnet only. It lists the off-chain endpoints the zSwap page reads — L2 read nodes, wide-range log nodes, the private pool's prover, Bitcoin APIs, the WalletConnect relay — curated on chain. The page merges each list ahead of the values it was built with and falls back to those. A listed endpoint can affect liveness and privacy; it cannot move funds.

Each list is keyed by service and the chain it serves. Order is failover order: the page tries #0 first. A chain with an empty list inherits the all chains list. Entries the page would skip are flagged. Changes reach a viewer on the page's next read of the contract, which it caches for up to six hours. Probes run from this page's origin, so a node that allows only zSwap's origins can fail here and still work there.
